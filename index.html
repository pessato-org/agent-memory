agent-memory · a field guide

How agents
remember.

A language model forgets everything between calls. Everything an agent seems to “know” about you was deliberately written down, stored somewhere, found again, and kept true. This is a visual guide to that machinery — the same memories, traced through files, SQL rows, vector spaces, and graphs.
